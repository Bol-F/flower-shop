# Sources and conventions

* Christophe De Cannière and Bart Preneel, *Trivium Specifications*, §2.1–2.2. This is the source of the fifteen tap positions, disjoint simultaneous shifts, loading constants and 4 × 288 initialization clocks. Our notation calls the preliminary sums a, b and c, and the three completed feedback bits t₁, t₂ and t₃. Position numbers on screen start at one. [Designers' paper](https://cr.yp.to/streamciphers/trivium/desc.pdf)
* Christophe De Cannière, eSTREAM reference implementation, preserved in SUPERCOP. The author's opening note explains the reversed sequence convention for key and IV. We use the default byte interface. The first loaded cell gets the high bit of the last supplied byte. The first generated bit is the low bit of the first output byte. The C code groups clocks into words. Our scalar Python model uses immutable snapshots. [Reference C, pinned copy](https://github.com/floodyberry/supercop/blob/a351f2c29235512a042d4b6989d241a67e86ad23/crypto_stream/trivium/e/submissions/trivium/e/trivium.c)
* ECRYPT Stream Cipher Project, 80-bit key and 80-bit IV known-answer records, preserved in AVR Crypto Lib. The four independent fixtures in `data/estream.json` are from sets 1, 2, 5 and 6, vector 0. For sets 1, 2 and 5 they include offsets 0, 192, 256 and 448 bytes. For set 6 the film checks the first 64 bytes. The sample key, IV and expected bytes were transcribed from the archive. All intermediate states, ciphertext and statistics are calculated independently. [Archived records](https://github.com/cantora/avr-crypto-lib/blob/b14938245d00969fde184d6c8490ff0d1a7ab7e1/testvectors/trivium-80.80.test-vectors)
* NIST SP 800-22 Rev. 1a, §2.1 and §2.3. The frequency and runs p-values use the published formulas, including the balance prerequisite for runs. A 4,096-bit sample illustrates these two statistics. A complete randomness battery or a security conclusion would require different evidence. [Publication](https://csrc.nist.gov/pubs/sp/800/22/r1/upd1/final)
* Manim Community Edition 0.22.1, Cairo. Original geometric artwork, typography, animation and narration script. [Scene API](https://docs.manim.community/en/stable/reference/manim.scene.scene.Scene.html) · [Animation composition](https://docs.manim.community/en/stable/reference/manim.animation.composition.AnimationGroup.html)
* English narration uses the synthetic American English voice `af_heart` from Hexgrad's Apache-2.0 Kokoro-82M v1.0 release. Locally rendered with kokoro-onnx, the official voice pack and the int8 ONNX conversion. Model files stay outside the source tree. The delivered audio is the generated performance. [Model card and license](https://huggingface.co/hexgrad/Kokoro-82M) · [Voice inventory](https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md) · [ONNX release files](https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0)
